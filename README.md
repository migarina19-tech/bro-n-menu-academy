# BRO&N Menu Academy

Мобильная учебная платформа для изучения меню BRO&N.

## Важно
В проект не внесены придуманные блюда или описания. Файл `script.js` специально оставляет `menuData` пустым до получения исходных материалов меню.

После добавления точных данных сюда можно подключить:
- карточки блюд;
- фотографии;
- категории;
- тесты;
- подсчёт баллов;
- порог сдачи (например, 80/100);
- сохранение прогресса.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн
- `script.js` — логика
